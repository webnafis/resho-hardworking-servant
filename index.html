Privacy Policy for RESHO (HARDWORKING SERVANT)

Last updated: September 2026

RESHO is an internal automation tool operated by Nafis Shahriar to generate, schedule, and publish educational content and video shorts across authorized social media channels.

Data Collection & API Usage

RESHO accesses external platforms solely through official developer APIs (including YouTube Data API and Meta Graph API) to automate video uploading:

  • Google / YouTube API: RESHO uses the youtube.upload scope strictly to upload video content directly to the developer's authorized YouTube channel. RESHO complies with the Google API Services User Data Policy.
  • Meta / Facebook API: Access is limited to page publishing permissions granted by the Page administrator.
  • We do not sell, store, trade, or share personal data with any third parties. Refresh tokens and API credentials are kept securely in private environment variables solely to authenticate automated tasks.

Data Retention & Revocation

Because RESHO does not collect external user data, no user profiles or personal records are stored. You can revoke access at any time:

  • For Google/YouTube: Manage permissions under Google Account Security > Third-party apps.
  • For Facebook: Manage access under Facebook Account Settings > Business Integrations.
